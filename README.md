## 📌 Задание по варианту №19

> Преобразовать строку, заменив все цифры на их словесные представления, если эти цифры кратны 2 (чётные), иначе — удвоить их и добавить перед ними знак «#».

### Логика преобразования:
- **Чётные цифры (кратные 2):**
  - `0` $\rightarrow$ `"zero"`
  - `2` $\rightarrow$ `"two"`
  - `4` $\rightarrow$ `"four"`
  - `6` $\rightarrow$ `"six"`
  - `8` $\rightarrow$ `"eight"`
- **Нечётные цифры:**
  - `1` $\rightarrow$ `"#11"`
  - `3` $\rightarrow$ `"#33"`
  - `5` $\rightarrow$ `"#55"`
  - `7` $\rightarrow$ `"#77"`
  - `9` $\rightarrow$ `"#99"`

### Пример работы:
- **Входная строка:** `A2b3c0!`
- **Выходная строка:** `Atwob#33czero!`
